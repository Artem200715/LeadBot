# LeadBot
Это мой 3-й pet-проект, бот может принимать заявки от пользователей, и передавать их сотрудникам
## Для чего был создан LeadBot?
В первую очередь он был создан для проработки 
новых для меня элементов, а именно:
- многопоточность бота
- новая система авторизации
- отправка сообщений от одного пользователя к другому
## Функционал
1. После ввода /start пользователю предлагают способы авторизации
   
<img width="954" height="648" alt="image" src="https://github.com/user-attachments/assets/84be6b2c-0b9a-4623-a948-f686294b1efd" />

2. После нажатия на одну из кнопок вылезет одинаковое для всех меню кнопок, отличается лишь повторение пароля при  регистрации, и что при вводе логина при входе в аккаунт, сразу определяется, входит сотрудник или обычный пользователь

## За обычного пользователя
3.1. При входе в аккаунт появляется меню, в котором присутствует две кнопки, "Создать заявку" и "Выйти из аккаунта"

<img width="347" height="151" alt="image" src="https://github.com/user-attachments/assets/1e4d6fe1-51da-41a5-8423-05d3949d5f31" />

4.1. После нажатия на кнопку "Создать заявку" пользователю предлагает поочерёдно ввести нужные данные, и после каждого ввода у пользователя спрашивает, правильно ли он всё написал

<img width="873" height="245" alt="image" src="https://github.com/user-attachments/assets/9a8958ae-573f-44a5-9595-373d3d52657c" />

5.1. После ввода всех нужных данных заявка создаётся, и в зависимости от того есть ли сейчас свободный, зарегистрированный работник, присылает сообщение об отправке

<img width="875" height="328" alt="image" src="https://github.com/user-attachments/assets/c096128a-bd08-4a1e-8d94-b90674344774" />

## За сотрудника
3.2. После входа в аккаунт, если есть только что созданные заказы, то-есть которые просто "висят" в базе данных, из них отправляется самый ранний, в ином случае работнику просто приходит сообщение о том что он вошёл в аккаунт с кнопкой "Выйти из аккаунта"

<img width="462" height="379" alt="image" src="https://github.com/user-attachments/assets/16b735ff-b646-4dd6-b3ef-9a8bb97063ad" />

4.2. Всего с заявкой есть 4 вида взаимодействия (кнопок 5 в общем, но по факту две из них отправляют эту заявку другому сотруднику, если такие есть):

- Взять в работу
- Отменить заявку(заявка закрывается и считается невыполненной)
- Отказаться от заявки(передать другому сотруднику)
- Завершить работу с заявкой

из того, что стоит показать, это передача заявки другому сотруднику, в таком случае, если свободных и зарегистрированных сотрудников нет, то заявка снова отправляется "висеть" в базе данных, пока её не возьмёт другой сотрудник
