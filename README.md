# LeadBot
Это мой 3-й pet-проект, бот может принимать заявки от пользователей, и передавать их сотрудникам
## Для чего был создан LeadBot?
В первую очередь он был создан для проработки 
новых для меня элементов, а именно:
- многопоточность бота
- новая система авторизации
- отправка сообщений от одного пользователя к другому

## За обычного пользователя
3.1. При входе в аккаунт появляется меню, в котором присутствует две кнопки, "Создать заявку" и "Выйти из аккаунта"

4.1. После нажатия на кнопку "Создать заявку" пользователю предлагает поочерёдно ввести нужные данные, и после каждого ввода у пользователя спрашивает, правильно ли он всё написал
<img width="873" height="245" alt="image" src="https://github.com/user-attachments/assets/9a8958ae-573f-44a5-9595-373d3d52657c" />
